# Краков вслух

Аудиогид по Старому Кракову, который срабатывает от геолокации. 28 точек, 115
глав, около 40 минут рассказа: от Барбакана и Флорианских ворот через Рынок,
Мариацкий костёл и университет вниз по Королевскому тракту на Вавель, дальше
Скалка, Казимеж и Подгуже. Список отсортирован с севера на юг, так что без GPS
его можно читать как маршрут.

Тексты написаны не как справка, а как рассказ о людях: трубач на башне, палач,
которому не подавали руки, вдова мясника за прилавком, прачки на Рудаве, шут
Станьчик, десятилетняя девочка с титулом «король». Даты стоят там, где без них
нельзя. Легенды прямо названы легендами.

В комплекте две сборки:

| | Что это | Как запустить |
|---|---|---|
| `krakow-vsluh.html` | Веб-версия, один файл, всё внутри | Открыть в Chrome на телефоне |
| `KrakowVsluh/` | Проект Android Studio, Kotlin + Compose | Собрать и поставить APK |

## Веб-версия

Работает офлайн после загрузки, ставится на домашний экран как приложение.
Умеет: определять ближайшую точку, показывать стрелку направления, вибрировать
при подходе, читать вслух через системный синтезатор речи.

Одна оговорка: Chrome даёт доступ к геолокации только на `https://` или
`localhost`. Если открыть файл напрямую из «Загрузок», кнопки и тексты будут
работать, а GPS может не включиться. Варианты:

- залить файл на GitHub Pages (перетащить в репозиторий, включить Pages) —
  минута работы, дальше открывается по ссылке и ставится на экран;
- либо просто пользоваться списком: точки выбираются вручную.

## Android-приложение

Требуется Android Studio (Ladybug или новее) и JDK 17.

```
File → Open → выбрать папку KrakowVsluh
дождаться Gradle sync
Run ▶ на телефоне с включённой отладкой по USB
```

APK для раздачи: `Build → Generate Signed App Bundle / APK → APK`.

Что внутри:

- `Stories.kt` — модель, чтение `assets/stories.json`, гаверсинус и азимут;
- `Narrator.kt` — обёртка над `TextToSpeech`, читает главы по очереди и отдаёт
  номер звучащего абзаца, чтобы подсвечивать его на экране;
- `MainActivity.kt` — весь интерфейс на Compose, `FusedLocationProvider` для
  координат, `TYPE_ROTATION_VECTOR` для стрелки-компаса.

Минимальная версия Android — 7.0. Разрешения только на геолокацию и вибрацию,
интернет не запрашивается вообще.

### Режим прогулки

Переключатель на главном экране. Когда включён, приложение само открывает
историю и начинает читать вслух, как только вы входите в радиус точки. Удобно
идти с наушниками и телефоном в кармане.

Ограничение: пока экран гаснет, чтение прерывается. Чтобы гид говорил с
выключенным экраном, нужен foreground-сервис с медиа-уведомлением — это
следующий логичный шаг, скажите, если нужно, добавлю.

## Голос

Кнопка «Голос» в шапке: список всех русских голосов, установленных в системе,
проба по нажатию, ползунки темпа и тембра. Настройки запоминаются.

Что сделано для живости звучания:

- текст перед озвучкой нормализуется (`SpeechText.kt`) — римские цифры
  разворачиваются в слова с правильным падежом («в XVI веке» → «в шестнадцатом
  веке»), сокращения раскрываются, тире превращается в паузу;
- реплика режется на фразы по знакам препинания, между ними вставляется тишина
  240–700 мс: пауза после заголовка длиннее, чем внутри абзаца;
- темп по умолчанию 0,92, тембр 0,92 — чуть медленнее и ниже стандартного.

### Мужской голос

Встроенный русский голос Google почти на всех телефонах женский, и выбирать там
не из чего. Бесплатный выход — движок **RHVoice** (Google Play или F-Droid), в
нём есть мужские Александр и Артемий:

```
Настройки → Специальные возможности → Синтез речи
→ выбрать RHVoice → скачать русские голоса
```

После этого они появятся в списке в приложении.

## Запись mp3

Системный синтез — потолок на уровне «понятно, но слышно машину». Чтобы получить
живого рассказчика, весь текст озвучивается заранее нейросетевым TTS и кладётся
в приложение файлами. Оба приложения ищут запись сами: нашли — играют её,
не нашли — читают синтезатором. Ничего переключать не нужно.

```bash
pip install requests
export TTS_KEY="ваш-ключ"

python3 tools/make_audio.py --dry-run                       # объём и цена
python3 tools/make_audio.py --engine openai   --voice onyx
python3 tools/make_audio.py --engine elevenlabs --voice <voice_id>
python3 tools/make_audio.py --engine yandex   --voice filipp
python3 tools/make_audio.py --engine google   --voice ru-RU-Wavenet-D
python3 tools/make_audio.py --only wawel                    # переозвучить одну точку
```

Скрипт кладёт файлы в `app/src/main/assets/audio/<id>/000.mp3` (вступление),
`001.mp3` и дальше по главам, пишет `manifest.json` и копирует всё в `web/audio/`.
Рядом лежит кэш хешей: правите одну главу — платится одна глава, остальные
пропускаются.

Объём — около 39 500 знаков. Порядок стоимости на сегодня: у OpenAI это
несколько центов, у Google и Yandex — доли доллара, у ElevenLabs — единицы
долларов; тарифы меняются, сверьтесь перед запуском. Готовый звук займёт
примерно 30–40 МБ, это нормальный размер для APK с офлайн-гидом.

Голоса, которые стоит попробовать первыми: `onyx` у OpenAI, `filipp` у Yandex,
`ru-RU-Wavenet-D` у Google — все мужские. У ElevenLabs выберите голос в кабинете
и подставьте его id; там же можно клонировать собственный, если хотите читать
своим голосом.

В настройках приложения появится переключатель «Читать синтезатором вместо
записи» — на случай, если захочется сравнить.

## Как добавить свои точки

Весь контент — в `app/src/main/assets/stories.json`. Формат:

```json
{
  "id": "planty",
  "title": "Планты",
  "subtitle": "Кольцо на месте рва",
  "lat": 50.06340, "lon": 19.93860,
  "radius": 80,
  "layers": ["город", "садовники"],
  "hook": "Одна фраза, ради которой человек остановится.",
  "chapters": [
    { "h": "Заголовок главы", "t": "Текст главы." }
  ]
}
```

`radius` — метры, в которых точка считается «достигнутой». На узких улицах
Старого города ставьте 40–60: GPS между высокими домами гуляет на 20–30 метров.
На открытом Рынке и Вавеле можно 90–120.

После правки JSON веб-версию нужно пересобрать — контент в неё вшит:

```bash
python3 build_web.py
```

## Про достоверность

Материал собран из общеизвестной истории Кракова. Спорные и легендарные сюжеты
помечены в самом тексте: оборванный хейнал, дракон, Эстерка, нож на цепи, ножка
Ядвиги. Перед тем как рассказывать это как факт группе туристов, стоит свериться
с краковскими источниками — историки последних лет многое из этого пересмотрели.
